# 中秋玉兔（dsh-anime-waifu）· DSH 二次元插件

给 DSH Web GUI 加一只**会说话、可拖动的中秋玉兔**（插件页显示名就叫「中秋玉兔」），外加**花瓣飘落**、**星夜闪烁**两套特效和
**碧蓝**、**星夜紫罗兰**两套二次元配色主题。全部工作都在浏览器半侧完成，不注册任何模型工具，不占用上下文 token。

![玉兔预览](assets/preview.png)

> 预览图裂开的话：GitHub 的仓库内图片由 `raw.githubusercontent.com` 提供，国内部分网络连接会超时（图片文件本身正常）。可参考 [GitHub520](https://github.com/521xueweihan/GitHub520) 修 hosts 或使用代理访问。

## 功能

### 玉兔形象

- 提灯月饼玉兔：白毛、黑豆眼、长耳、手提金灯笼、莲纹月饼、桂花；默认停在屏幕右下角（可改左下角）。
- **两种形象随时切换**：默认用生成的玉兔图，设置面板「形象」一键切回手绘 SVG。
- **待机动作**：呼吸浮动、定时眨眼、长耳轻摆。
- **干活时走动**：智能体正在执行任务时，兔子两条腿交替迈步、身体随步频轻轻起落；任务结束就站定，只做呼吸浮动。
- **拖动定位**：按住兔子拖到任意位置，位置会被记住；窗口缩放时自动收敛回可视区。
- **会说话**：点一下随机说一句台词；闲置一段时间会主动开口；模型正在输出时显示「在写了」。
- **显示 / 隐藏**：✕ 按钮，或快捷键 `Ctrl+Shift+A`。

### 特效

- **花瓣飘落**：默认 14 片随机大小、时长、延迟的蓝色花瓣，数量和速度可调；系统开启「减少动态效果」时会自动收敛。
- **星夜闪烁**：默认 20 颗随机分布的闪烁星点，数量可调。

### 二次元配色主题

- 内置**碧蓝**（浅色蓝）与**星夜紫罗兰**（暗色紫）两套第三方主题，另外可选「跟随内置外观」。
- 平台的「设置 → 通用 → 外观」只有 浅色 / 深色 / 跟随系统 三档，所以这两套配色在本插件的设置面板和插件页卡片里切换；选择会记住，重启后自动套用。

### 设置面板

点兔子右上角的齿轮打开，所有改动即时生效并记在本机：

| 分区 | 可调项 |
| --- | --- |
| 显示 | 显示 / 隐藏、大小、不透明度、停靠角落、距屏幕边缘距离 |
| 形象 | 生成图 / 手绘 SVG |
| 动作 | 智能体干活时是否走动、走动速度 |
| 说话 | 主动说话间隔、气泡停留时间、台词列表（一行一句） |
| 特效 | 花瓣开关与数量、速度；星夜开关与星点数量 |
| 主题 | 碧蓝 / 星夜紫罗兰 / 不套用 |

### 插件页卡片

「设置 → 插件 → 中秋玉兔」详情页里有一张卡片：实时状态、一键开关、切换主题、打开设置面板、手动试走一次。

## 安装

### 方式一：应用内安装（推荐）

「设置 → 插件 → 添加插件」里填**绝对路径**（相对路径会被拒绝）：

    <本仓库>\dist\dsh-anime-waifu-0.10.7.tgz                    ← 本地 tarball
    <本仓库根目录>                                               ← 本地目录（link）
    https://github.com/yigehai/dsh-anime-waifu/releases          ← 或从 Releases 下载附件

- 用 **tarball** 装：装完刷新页面就能看到玉兔。
- 用**本地目录**（link）装：需要**完整重启一次 DSH**，之后改代码只刷新页面。
- 从**本地目录**换成 **tarball** 时，先在插件页卸载，再装 tarball，然后**完整重启一次**。

### 方式二：命令行（只对非 desktop profile 成立）

    dsh plugin --profile tui add <本仓库>/dist/dsh-anime-waifu-0.10.7.tgz

桌面版的 desktop profile 只能走方式一，命令行会被拒绝。

### 卸载

在「设置 → 插件」里卸载 `dsh-anime-waifu`，然后完整重启一次 DSH。兔子、特效、主题与设置都会被清理干净。

## 使用

- 点一下兔子：随机说一句台词。
- 拖动兔子：换位置，松手即保存。
- 齿轮：打开设置面板，所有改动即时生效。
- ✕ 或 `Ctrl+Shift+A`：藏起来 / 叫出来。
- 主题、特效在设置面板与插件页卡片里都能切。

## 配置（部署默认值，可选）

想给整个部署定一套默认值，写进 profile 的 `cordis.patch.yml`：

    - id: anime-waifu
      name: 'dsh-anime-waifu'
      config:
        enabled: true            # 是否显示玉兔
        size: 133                # 宽度 px（80-360）
        opacity: 1               # 不透明度（0.3-1）
        position: right          # right | left
        sakura: true             # 花瓣飘落
        stars: true              # 星夜闪烁
        theme: 'off'             # off | anime-azure | anime-night
        artStyle: 'raster'       # raster=生成图 | svg=手绘矢量
        idleSeconds: 60          # 主动说话间隔秒（15-600）
        petalCount: 14           # 花瓣数量（0-60）
        petalSpeed: 1            # 飘落速度倍率（0.2-3）
        starCount: 20            # 星点数量（0-120）
        dockMargin: 16           # 距屏幕边缘距离 px（0-160）
        bubbleSeconds: 6.5       # 气泡停留秒（1-30）
        zIndex: 2147482000       # 叠放层级（1000-2147483000）
        walkWhenBusy: true       # 智能体干活时是否走动
        walkSpeed: 1             # 走动速度倍率（0.5-2）
        lines: ['今天也一起加油吧～']

- 这些是**用户没改过**时的默认值；在本机面板里改过的值存在浏览器里，优先级更高（面板里的「恢复默认」可以清掉）。
- patch 是**整块替换**：要改哪个键，都得把整份 config 重述一遍。

## 常见问题

| 现象 | 怎么办 |
| --- | --- |
| 插件装好了，页面却没有玉兔 | 刷新一次页面；用本地目录安装的要完整重启一次 DSH |
| 启用失败，提示 `failed to import` | 之前用「本地目录」热装过：**完整重启一次 DSH** 即可（卸载 + 改装 tarball 不会改变这个结果） |
| 插件页里没有卡片 | 安装后需要完整重启一次；确认装的是完整包 |
| 玉兔空白 / 只有气泡 | 生成图被页面策略拦截时会自动回退手绘 SVG；也可以在面板里手动切到「手绘 SVG」 |
| 看不出在走动 | 走动的整轮约 1.2s；系统开启「减少动态效果」时会放慢到 2.6s |
| 主题按钮是灰的 | 组合里没有主题服务（`@deepseek-ai/dsh-client-ui-theme`） |
| 主题列表里没有新配色 | 第三方配色不会出现在平台「外观」开关里，用本插件的设置面板 / 卡片切换 |
| 改了 config 不生效 | patch 是整块替换；或本机浏览器里已有同名偏好（面板里「恢复默认」清掉） |
